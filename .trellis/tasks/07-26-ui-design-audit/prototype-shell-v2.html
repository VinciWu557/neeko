Neeko · 本轮样式改动点清单

6 个改动点 · 全部是纯 class / token 替换 · 布局与几何零改动
这份不是界面效果图。 上一版原型画的是「理想中的完整界面」，看起来像在重新设计整个 App —— 与「不改动当前布局，只做样式 UI 优化」冲突，已废弃。
下面每个样例的布局完全一致（同样的元素、同样的间距、同样的尺寸）， 唯一的差别是颜色 / 焦点态 / 分割线 —— 那正是本轮要改的东西。
1 错误提示没有颜色（真 bug） LspPanel.tsx:208 · LspCustomServersSection.tsx:96,214 · HtmlPreview.tsx:171
问题：这 4 处用 text-status-error，但主题只定义了 --status-failed，tailwind 只映射了 --color-status-{idle,running,failed} —— 没有 --color-status-error。Tailwind 根本不生成这个类， 所以错误提示没有红色（就挨着有颜色的 text-status-failed）。
修法：主题补 --status-error: var(--status-failed) alias + tailwind 补映射。只改 CSS 定义，不改任何组件。
现状 · 类不存在

Command not found

text-status-error → 无对应样式
目标 · 有颜色

Command not found

text-status-error → --status-error → --status-failed
2 accent 底色上的白字 → text-on-accent 全仓 36 处（ui/Button、ToggleGroup、Checkbox、ErrorBoundary、TerminalPanel、RemoteDialog、WSLDialog…）
问题：bg-accent-blue 底上写死 text-white。 主题里已有 --text-on-accent（随主题变）—— dark 下是深色， Claude / Light 下不同。写死白字在某些主题下对比失效。
修法：text-white → text-[var(--text-on-accent)]。纯 class 替换。
现状 · 写死白
bg-accent-blue text-white
目标 · 随主题
bg-accent-blue text-[var(--text-on-accent)]
darktext-on-accent = 深色
lighttext-on-accent = ?
claudetext-on-accent = ?
one-darktext-on-accent = ?
3 暗色假设的分割线 39 处 border-white/ · bg-white/（Settings 面板最多）
问题：border-white/[0.04] 假设底色是暗的。 Light / Claude 主题下这条线会消失或发脏。
修法：→ border-border（= --border-color，随主题变）。纯 class 替换。
现状 · 白色半透明
Custom server
border-b border-white/[0.04]
目标 · 语义 token
Custom server
border-b border-border
darkwhite/4% ≈ 不可见
lightwhite/4% ≈ 看不见
claudewhite/4% ≈ 看不见
one-darkwhite/4% ≈ 不可见
4 键盘焦点不可见 DockBarButton.tsx:48 · ToolbarFooter.tsx:49,78 · ui/Badge.tsx:7
问题：focus:outline-none 之后没有任何替代 —— 键盘用户 Tab 到主导航上看不到焦点在哪。
修法：补 focus-visible:ring-2 focus-visible:ring-accent-blue。纯 class 追加。
现状 · 无焦点环
focus:outline-none（无替代）
目标 · focus-visible 环
focus:outline-none focus-visible:ring-2 focus-visible:ring-accent-blue
5 Settings 选中态：大色块 → surface SettingsSidebar.tsx:72,102 · SettingsPanel.tsx:197,257
问题：选中项用整块高饱和 !bg-accent-blue， 5 个主题下都刺眼，且与 Dock 的 bg-bg-selected 选中语言不一致。
修法：→ bg-bg-selected text-text-primary + 左侧 2px 指示条。 纯 class 替换，DOM 结构与间距不变。
现状 · 大色块
Appearance

目标 · surface + 指示条
Appearance
bg-bg-selected text-text-primary + 指示条
6 主题逃逸：硬编码色 → 语义 token 9 处（SessionChips / ContextMenu / prDisplay / ChangesSection / PRDetail* / TabOverflowMenu）
问题：Git 面板写死 GitHub 的绿红紫（#3fb950 / #f85149 / #a371f7），在 Light / Claude 主题下 与整个界面不搭。
修法：接回主题已有的 --git-status-* / --diff-*（覆盖全部 5 个主题）—— 不需要新建色板。纯 class 替换。
